# WaveBreaker-Map

## Purpose

This repository is used to collaboratively maintain and update the WaveBreaker map. It allows contributors to work together on territorial changes, borders, and other map updates while keeping changes organized and trackable through Git.

## Guidelines

- **One nation per layer:** Each nation's territory must be on its own dedicated layer.
- **Use clear names:** Name layers using the nation's tag (e.g., `WB-Map-UFP`).
- **Preserve existing layers:** Do not merge, flatten, or delete layers unnecessarily.
- **Respect other territories:** Avoid modifying another nation's territory without coordination.
- **Keep borders consistent:** Check neighboring territories when making border changes.
- **Follow the lore:** Territorial changes should reflect established WaveBreaker lore and agreements.
- **Keep changes focused:** Avoid unrelated edits and unnecessary file changes.

## Workflow

1. Pull the latest changes before editing.
2. Make your changes and save your changes to the main project file.
3. Maps should be exported from the proj file with only the applicable layers enabled.
4. Review your changes before committing.
5. Use clear commit messages describing what changed.
6. Coordinate major changes affecting multiple nations before merging.

## Important

**Keep the map organized, preserve separate territory layers, and coordinate changes with other contributors.**
